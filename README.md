This is a ETL project which does the analysis on food order history, the dataset is taken from kaggle.

Dataset is cleaned, only some features are extracted and then analysis is done.

The cleaned dataset is uploaded to data warehouse, PostgreSQL in our case.

The internal data is then integrated with the external data, available online and then analysis is done in deeper manner, to understand the customer behaviour and provide more insight scope.

Then the combined analysis is done1, power bi is used for visualization.
